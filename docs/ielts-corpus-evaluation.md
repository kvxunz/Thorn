# 雅思批量评测与引擎优化

## 来源与范围

输入来自 [Cambridge IELTS 4 General Training Test 2 的第三方转录](https://engnovate.com/ielts-reading-tests/cambridge-ielts-04-general-training-reading-test-2/)，包括度假预订、学院课程、复印服务、蜜蜂行为等正文。另一套 Cambridge 17 页面返回 HTTP 429，本轮没有将其计入语料。

从 transcript 容器提取正文段落，用 spaCy 英文 sentencizer 切句、去重，要求至少五个空格分词及终止标点。明确排除标题、指示语、营业时间和商家广告区，不将地址、时间表和广告片段当作长难句。初次抽取 115 条候选，清理后 100 句；不是为了凑整数截取，也没有只选解析成功的句子。原文、逐句解析树保留在仓库外的临时目录；报告只保存哈希和 token 索引。

出版社版本未逐字核对，难度未独立评级。英文句子切分仍是启发式，报告不声称来源零误差。

## 检查强度

| 层次 | 数量 | 实际检查 |
| --- | ---: | --- |
| 全体语料 | 100 句 | 非空解析、依存图诊断、顶层 token 完整不重复、子节点包含及兄弟不重叠 |
| 开发集 | 84 句 | 用于发现问题；其中 23 句固化了语法预期 |
| 预留集 | 16 句 | 未导出逐句树用于规则修订；目前只检查结构，不是语法准确率盲测 |
| 已固化语法预期 | 23 句、82 项 | 主干角色、疑问词功能、部分从句边界和直接父节点，全部通过 |

预期由助手审阅原句后编写，不是模型输出自动充当金标，也不是独立人工标注。其余句子没有完整语法断言；23 句中的未断言关系也不算已验收。测试通过不能掩盖下表中的已知问题。

分组使用句子 SHA256 前八位对 5 取余，余数为 0 的进入预留集；此前已经用于调试的五句强制进入开发集。原网页曾被阅读，因此不能声称独立、从未接触过的盲测。

## 本轮修正

1. 展示层不再把倒装结构的助动词、主语、实义谓语合成一个“谓语”父节点。源文本顺序不变，主语继续以独立角色显示；同时修正否定倒装、条件倒装等已有快照中的六处同类结构。
2. 直接疑问句的单词疑问词保留结构层给出的主语、宾语或状语角色，不再一律变成连接词后又被展示层改为状语。关系从句、内容从句及非疑问结构的原有处理不变。
3. 增加不同词汇的四个疑问句回归，另为语料提取、去重、分组、角色/父节点断言和跨度检查增加四项快速测试。

没有新增翻译缓存，也没有更换底层模型。此次为通用角色/展示规则修正，不按雅思原句字符串打补丁。

## 验证与边界

- 新增问题族回归在修复前实际出现 6 个失败，修复后通过；另外添加依存中心词、来源和反例检查。

- 这表示上述已记录缺陷已闭环，不表示任意英语句子都能正确解析。100 句中仍只有 23 句有定向语法预期，其余不是人工验收金标；原有外部差异和独立盲标缺口不因本轮通过而消失。
- 引擎改动已提交并推送：`ab4b0a2`；当前 App 已替换安装并验证安装包内的引擎。该提交的 [CI](https://github.com/kvxunz/Thorn/actions/runs/34747294283) 与 [Live parse regression](https://github.com/kvxunz/Thorn/actions/runs/34747294285) 均通过。


## 复现

先将 `MODEL_PYTHON` 设为现有 sidecar 模型环境的 Python 可执行文件。无需更改应用安装，也不要将完整网页提交到仓库。

```sh
curl -fL --max-time 45 https://engnovate.com/ielts-reading-tests/cambridge-ielts-04-general-training-reading-test-2/ -o /private/tmp/thorn-cambridge4.html
"$MODEL_PYTHON" scripts/ielts_corpus_probe.py /private/tmp/thorn-cambridge4.html \
  --source https://engnovate.com/ielts-reading-tests/cambridge-ielts-04-general-training-reading-test-2/ \
  --gold docs/reports/ielts-reviewed-expectations.json
```

`--review-dir /private/tmp/thorn-ielts-review-new` 可导出开发集原句、token 索引及树以便复核，不能指向仓库内。网页变化导致已标注句子消失时，脚本显式失败，不静默跳过。`docs/reports/ielts-corpus.json` 是本轮 100 句的实际报告。
