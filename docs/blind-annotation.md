# 新材料独立盲标交接

状态：等待真人提供新材料并完成标注；尚未完成盲标。

请两位英语熟练者各自选择并标注未用于本项目调试的句子，标注期间不查看 Thorn
输出、外部评测报告或对方答案。建议覆盖叙述、学术、对话、长修饰链、并列和省略。
每人先独立填写以下模板，再由第三人或双方讨论裁决分歧；保留原始两份答案。

每句模板（复制填写；不要预填模型答案）：

```json
{
  "id": "new-001",
  "text": "",
  "source": "",
  "annotator": "",
  "annotated_at": "",
  "model_output_seen": false,
  "main_predicate": "",
  "subjects": [],
  "objects_or_complements": [],
  "modifiers": [{"phrase": "", "modifies": "", "reason": ""}],
  "coordination_groups": [],
  "acceptable_alternatives": [],
  "uncertainties": []
}
```

用原文中的完整短语或字符范围定位重复词。不得把解析器的中心词约定当作唯一合法
语法解释。完成标注后先冻结文件及 SHA-256，再运行模型；记录各项命中和所有分歧。
材料提供者应确认文本可用于评测，去除隐私信息。提交此模板不代表真人已完成工作。

## 接收校验

将两人的记录合并为 JSON 数组，保留每句两条原始记录，执行：

```sh
python3 scripts/check_blind_annotations.py /path/to/annotations.json
```

校验器要求每句两位不同标注者、明确声明未看模型输出、原文一致、必填字段完整、
主干与修饰短语可定位到原文，并检查并列组格式。它输出文件 SHA-256 和所有答案
差异；存在差异时退出码为 1，须先裁决，不会自动采用模型意见覆盖人工答案。
格式通过不等于身份或盲标独立性已验证，更不等于解析器通过这些标注。当前仍未收到
真人材料，不能将这个校验工具的完成记作独立盲标完成。
